How these are measured

PR wait = "PR created" checked → "PR approved" checked.
CR wait = "Test plan attached" checked (fully in EdTech's hands) → "CR approved" checked.
EdTech wait per card = its PR wait + its CR wait, including waits still running today.
Deployment cycle = card created → moved to "Deployed to Prod". Averages only count finished waits/shipped cards; timestamps started being recorded 2026-07-09, so older cards may not have wait data.
